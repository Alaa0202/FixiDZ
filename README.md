# FixiDZ

A web application for managing a repair shop (phones, computers, tablets) for a shop in Algeria.
Software Engineering course project.

## Features

Repairs (creation, tracking, statuses) · Spare parts inventory · Payments and warranties · Dashboard · Reports · Shop settings.

## Repository structure

```
frontend/   User interface
backend/    API and database
docs/       Documentation and prototype (docs/prototype/index.html)
```

## Tech stack

React + Vite + Tailwind CSS · Node.js + Express · PostgreSQL + Prisma · JWT · Chart.js
